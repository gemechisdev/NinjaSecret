# Assets Directory

This directory contains static assets for the bot such as images, fonts, and other media files.

## Usage
Place your bot's assets here for easy access and organization. Common asset types include:
- Images (.jpg, .png, .gif)
- Fonts (.ttf, .otf)
- Audio files (.mp3, .wav)
- Video files (.mp4, .avi)
